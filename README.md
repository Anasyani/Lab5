## 📌 Описание задания

Подключить к проекту MySQL, создать таблицу для данных формы, сохранять данные формы в БД через PHP (PDO) и выводить их на странице. Для работы с таблицей использовать класс PHP. В Docker: nginx, PHP-FPM, MySQL, Adminer.

---

## ⚙️ Как запустить проект

```
git clone <ссылка на репозиторий>
cd lab5
docker-compose up -d --build
```

- Сайт: `http://localhost:8080`
- Форма: `http://localhost:8080/form.html`
- Adminer: `http://localhost:8081` (система: MySQL, сервер: `db`, пользователь: `lab5_user`, пароль: `lab5_pass`, база: `lab5_db`)
- MySQL локально: `mysql -h 127.0.0.1 -P 3307 -u lab5_user -p lab5_db`

MySQL при первом запуске инициализируется около 20–30 секунд. Если сайт сначала показывает «Ошибка подключения», нужно немного подождать и обновить страницу.

## 📂 Содержимое проекта

- `docker-compose.yml` — сервисы `nginx` (8080), `php` (сборка из `Dockerfile`), `db` (MySQL 8.0, порт 3307), `adminer` (8081)
- `Dockerfile` — PHP-FPM с расширениями `pdo` и `pdo_mysql`
- `nginx/default.conf` — конфиг Nginx с PHP-FPM
- `db/init.sql` — создание таблицы `students` при первом запуске БД
- `www/db.php` — подключение к БД через PDO
- `www/Student.php` — класс для работы с таблицей (`add`, `getAll`, `update`, `delete`)
- `www/process.php` — обработка формы и сохранение в БД
- `www/index.php` — вывод сохранённых данных
- `www/form.html` — форма

---

## 🧪 Ход работы

1. **Docker.** Подготовлен `Dockerfile` для PHP-FPM с расширениями MySQL, в `docker-compose.yml` добавлены сервисы `db` (MySQL) и `adminer`.
2. **Подключение к БД.** В `db.php` создаётся PDO-подключение к хосту `db` с режимом ошибок `ERRMODE_EXCEPTION`.
3. **Таблица.** Создана таблица `students` (`id`, `name`, `age`, `faculty`, `agree_rules`, `study_form`).
4. **Класс `Student`.** Методы `add`, `getAll`, `update`, `delete` выполняют запросы через подготовленные выражения.
5. **Обработка формы.** `process.php` получает данные из `$_POST`, добавляет запись в БД и перенаправляет на `index.php`.
6. **Вывод.** `index.php` получает все записи через `Student::getAll()` и выводит списком.
